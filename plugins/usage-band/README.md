# usage-band

A Claude Code mod: a band above the prompt with context fill (bar and %), tokens used of the window,
session token totals (in/out) and cost so far when available. Based on the token-weather sample in
anthropics/claude-code-playground. Needs Claude Code 2.1.287 or later.

```
/plugin marketplace add QuantiCZ/claude-code-mods
/plugin install usage-band@quanti-mods
```
